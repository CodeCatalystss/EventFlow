# EventFlow

EventFlow is a simple and powerful platform for college students to find and join campus events. It brings all college activities together in one place, so you never miss out on workshops, fests, or club meetings.

## Features
- **Easy Discovery**: Quickly find events by category or search.
- **Fast Registration**: Sign up for any event with just one click.
- **Admin Dashboard**: Tools for clubs to create events and manage students.
- **Event Calendar**: A clear view to plan your schedule by date.
- **Secure Login**: Safe and easy access for students and organizers.

## Who it is for
- **Students**: To stay updated and participate in campus life.
- **Club Organizers**: To manage events professionally and reach more students.
- **College Admins**: To keep track of all campus activities.

## Tech Stack
- **Frontend**: React, Vite, TypeScript
- **Styling**: Tailwind CSS, Shadcn UI
- **Database**: Supabase (PostgreSQL)
- **Data Fetching**: TanStack Query

## Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Create a `.env` file and add your Supabase details:
```env
VITE_SUPABASE_URL=your_url
VITE_SUPABASE_ANON_KEY=your_key
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
